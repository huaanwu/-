# 持仓规律与交易纪律

> 融合 **毛泽东(军事哲学)** · **巴菲特 + 芒格(价值投资)** · **利弗莫尔 + 索罗斯(动量/反身性)** · **段永平 + 张磊(经营/赛道)** · **用户反向纪律**,提炼为 5 大类持仓规律 + 12 条细则。
> 既人类可读,也是 reverse-watch 中 `HoldingRules` 模块与 AI 总管的硬约束。

## 二、5 大持仓规律(融合产出)

### 规律 1 · 仓位上限 —— "集中优势兵力,但不孤注一掷"

| 维度 | 阈值 | 出处 |
|---|---|---|
| **单票上限** | 总资产 10% | 毛选(集中)/ 巴菲特(集中投资)/ 利弗莫尔(单笔可控) |
| **底仓上限** | 总资产 50% | 张磊(长期持有好生意) |
| **短线试水** | 单笔 1%-5% | 毛选(灵活机动)/ 段永平(不为清单:不重仓追) |
| **现金储备** | 总资产 ≥5% | 巴菲特(永远有钱买便宜货) |
| **股票总仓** | ≤95% | 毛选(留预备队) |

**默认参数**(可调):
```js
singleStockMaxPct: 0.10    // 10%
basePoolMaxPct:    0.50    // 50%
shortTermMaxPct:   0.05    // 5%
cashReservePct:    0.05    // 5%
totalStockMaxPct:  0.95    // 95%
```

---

### 规律 2 · 止损纪律 —— "打得赢就打,打不赢就走"

| 情景 | 止损线 | 出处 |
|---|---|---|
| **短线试水** | 买入价 -5% 强制离场 | 利弗莫尔(截断亏损)/ 巴菲特(Rule No.1) |
| **中线持有** | 跌破 MA20 且 2 日不收复 | 毛选(灵活机动) |
| **底仓(高分红/好生意)** | 跌破 MA60 + 基本面变差才走 | 张磊(长期主义) |
| **月度总回撤** | -8% 触发熔断(本月不再开新仓) | 巴菲特(never lose money) |
| **单票回撤** | -10% 强制复盘(假设是否成立) | 芒格(invert: 最坏情况是什么) |

**默认参数**(可调):
```js
shortStopLossPct:    0.05    // -5%
midStopBelowMA:      20      // MA20
baseStopBelowMA:     60      // MA60
monthlyMaxDrawdown:  0.08    // -8%
singleReviewPct:     0.10    // -10% 强制复盘
```

---

### 规律 3 · 集中度控制 —— "不要把鸡蛋放在一个篮子里,也不要放在 50 个篮子里"

| 维度 | 上限 | 出处 |
|---|---|---|
| **单票** | 10% | 规律 1 |
| **单行业** | 25% | 张磊(赛道分散)/ 段永平(不为清单:不重仓单一行业) |
| **同一买入假设** | 30%(同时 3 笔以内的同一逻辑) | 巴菲特(集中投资,避免重复下注同一假设) |
| **4 池分布** | 底仓 50% / 龙头 0%(只看不接) / 替身 ≤30% / 陷阱 0%(只标记) | 用户反向纪律 |

**默认参数**(可调):
```js
singleIndustryMaxPct: 0.25
sameAssumptionMaxPct: 0.30
```

---

### 规律 4 · 加仓规则 —— "只在盈利上加仓,不在亏损上加仓"

| 情景 | 加仓条件 | 出处 |
|---|---|---|
| **短线** | 浮盈 ≥+5% 且未触发止盈才考虑加仓 | 利弗莫尔(Never average down) |
| **中线** | 突破前高 + 量价齐升 + 板块强度维持 ≥60% | 索罗斯(趋势确认才重仓) |
| **底仓** | 年报后估值仍低于历史中位 + ROE 维持 | 巴菲特(好生意越便宜越买) |
| **加仓比例** | 每笔不超过原始仓位的 50% | 毛选(集中优势兵力:不一次用尽) |
| **加仓冷却** | 同票加仓间隔 ≥3 个交易日 | 利弗莫尔(不冲动) |

**默认参数**(可调):
```js
addOnProfitPct:  0.05    // 短线浮盈 ≥5%
addMaxRatio:     0.50    // 加仓不超过原仓 50%
addCooldownDays: 3       // 间隔 3 天
```

---

### 规律 5 · 清仓规则 —— "该走就走,绝不恋战"

| 情景 | 清仓条件 | 出处 |
|---|---|---|
| **止损触发** | 规律 2 的 5 条任意一条 | 巴菲特 |
| **买入假设失效** | 假设的 3 个支撑条件任意 2 个消失 | 芒格(invert) |
| **基本面变脸** | 业绩同比 -30% 或 商誉/净资产 >30% 或 减持公告 | 段永平(stop doing: 不持有烂生意) |
| **板块清池** | 板块强度 3 日 <50% → 该板块所有持仓减半 | 用户反向纪律 / 毛选(主力转移) |
| **鱼尾行情** | 个股 5 日涨幅 >15% → 强制减半 | 段永平(不为清单:不接最后一棒) |
| **陷阱锁定** | 量化席位 >3 / 鱼尾 → 锁 24h 禁接 | 用户反向纪律 |

**默认参数**(可调):
```js
fishTailTrimPct:   0.15    // 5 日 +15% 鱼尾
sectorWeakPct:     0.50    // 板块强度 <50%
trapLockHours:     24      // 陷阱锁定时长
```

## 四、与原"交易纪律十二条"的关系

| 纪律十二条 | 映射到持仓规律 |
|---|---|
| 1. 无数据不交易 | (UI 层:数据缺失告警) |

| 3. 集中优势兵力 | 规律 1 + 规律 3 |

## 五、AI 总管引用方式

每次 AI 分析个股时,prompt 顶部自动追加:

```
【持仓规律摘要】
- 单票 ≤10% / 底仓 ≤50% / 短线 ≤5%
- 短线止损 -5%, 中线破 MA20 走, 月度回撤 -8% 熔断
- 单行业 ≤25%, 同假设 ≤30%
- 加仓: 短线浮盈 ≥5% 才考虑, 加仓 ≤原仓 50%, 间隔 ≥3 天
- 清仓: 鱼尾 5 日 +15% 减半, 板块弱 <50% 减半, 陷阱锁 24h

【自学习】
- 用户上次对本规则的反馈: ✓ 采纳 / ⚠ 部分 / ✗ 否定
- 本月该规则触发 X 次, 盈亏分布: Y
```
